---
title: Bruin CLI and Renart
description: When to use Bruin CLI and when to use Renart.
---

Bruin CLI and Renart work on the same projects, but they support different working styles.

## Bruin CLI

Bruin CLI is a better fit when you want a more coding-oriented, terminal-first experience.

Typical cases:

- editing files directly in your editor
- running commands from the terminal
- working in a script-heavy or automation-heavy loop

## Renart

Renart is a better fit when you want a faster visual workflow.

Typical cases:

- exploring a pipeline on a canvas
- understanding dependencies and lineage quickly
- editing assets with more context around them
- inspecting and running work without leaving the workspace view

## Same project model

Both work against the same underlying project files. Renart is not a separate project format.
