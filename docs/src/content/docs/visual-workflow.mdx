title: Visual Workflow
description: Work with pipelines visually while staying close to the real files.
---

Renart is built around a visual workflow rather than a purely file-by-file loop.

## Canvas first

The canvas helps you understand:

- which assets exist in a pipeline
- how dependencies connect
- how data flows through the project
- what is upstream or downstream

## Edit with context

Renart keeps the canvas, editor, and results close together so it is easier to:

- inspect an asset while editing it
- follow lineage while changing SQL
- create or rename assets in context
- run an asset or a whole pipeline from where you are working

## Still based on real files

Even though Renart is visual, the underlying project remains a real workspace on disk. That keeps the workflow friendly to Git, review, and collaboration.
