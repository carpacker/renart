Renart is the fast visual workspace for Bruin projects.

It is designed for people who want to inspect, edit, and run pipelines quickly while keeping the underlying project in version-controlled files.

## Good fit for

- Data engineers building pipelines
- Analytics engineers working in SQL-heavy projects
- Technical data users who want a more visual workflow around Bruin projects

## What Renart helps with

- Seeing assets, dependencies, lineage, and data flow on a canvas
- Editing pipelines faster than working only through YAML and SQL files
- Running inspect and materialization flows from the same workspace view
- Staying close to real project files that work well with Git
