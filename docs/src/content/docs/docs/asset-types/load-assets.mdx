A Load asset replicates data between two connections — from a source
database, storage bucket, or file into the warehouse your pipeline runs
on. It's how raw data usually enters a pipeline: no code, just a source
and a target.

## Create one

On the canvas, add an asset and choose **Load**. Instead of a code editor,
the main pane is a form:

- **Source connection** and **source table** — where the data comes from.
  The connection picker is grouped into databases, storage, and files;
  once a source connection is chosen, Renart lists its available tables so
  you pick rather than type.
- **Destination connection** and **destination table** — where it lands,
  usually your warehouse connection and a `schema.table` name.
- **Mode** — how each run writes.

Local files are a first-class source: choose the **local** entry and point
the source at a file path (for example `data/exchange_rates.csv`) to load
a CSV that lives in your repository.

## Modes

| Mode | Each run… |
| --- | --- |
| `full-refresh` | Replaces the target table with the source's current contents. |
| `incremental` | Appends or merges new records instead of rewriting everything. |
| `truncate` | Empties the target, then loads. |

## Columns and lineage

The upstream dependency is inferred from the source when you save, so the
Load asset takes its place on the canvas automatically. Use **Infer
columns** to read the source's schema into the asset's column list — after
that, downstream SQL assets get completions and type checking against the
loaded table like any other upstream.
