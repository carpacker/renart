## Start Renart

From `renart/`:

```bash
go run . web
```

Renart opens the local URL in your default browser after the server is ready. To skip that behavior in scripts or CI, pass `--no-open`:

```bash
go run . web --no-open
```

If you want to point Renart at a specific Bruin binary:

```bash
go run . web --bruin-binary /path/to/bruin
```

## Local validation flow

```bash
go build .
cd web
corepack pnpm test:e2e:live
```

## Workspace model

Renart works directly against the files in your project workspace. Changes made through the UI are meant to stay compatible with a Git-based workflow.
