---
title: Who Renart Is For
description: The users and workflows Renart is designed around.
---

Renart is built for people working with data pipelines in Git-backed projects.

## Primary users

- Data engineers
- Analytics engineers
- Technical data analysts and data developers working inside pipeline projects

## Best fit

Renart is a strong fit when you want:

- a visual editor for pipelines that still live in version control
- a canvas-based view of assets, dependencies, lineage, and data flow
- a faster alternative to editing only YAML and SQL files by hand
- a workflow where inspecting and running pipelines feels immediate
